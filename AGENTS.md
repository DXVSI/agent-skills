# Repository conventions

- Write skill instructions, examples, and repository documentation in English.
- Keep each skill self-contained in `skills/<skill-name>/` with a valid `SKILL.md` entrypoint.
- Use `metadata.author: DXVSI` for skills authored here. Preserve upstream authorship and source attribution for adaptations.
- Keep factual uncertainty, exact quotations, and structured data intact when revising examples.
- Verify local Markdown links and skill frontmatter before publishing changes.
- Commit and push only when the user requests publication or explicitly authorizes those operations.
