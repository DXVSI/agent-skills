# Editing examples

All examples are fictional. They do not describe completed work or the user's actual results.

## Report a change

Given: a duplicate request on a double click was fixed; the local test passes; the server has not been checked.

Weak: "We delivered a major improvement that takes reliability to the next level and ensures a flawless user experience."

Better: "Fixed the duplicate request on a double click. The local test passes. I have not checked it on the server yet."

## Report a measurement

Given: in one local scenario, p95 response time fell from 300 to 210 ms.

Weak: "The system is significantly faster, demonstrating the effectiveness of our comprehensive approach."

Better: "In the local test, p95 response time fell from 300 to 210 ms. Other scenarios have not been measured."

Keep the metric, units, and conditions. Do not turn one measurement into a claim about the entire system.

## Preserve uncertainty

Given: an error spike coincided with a release; its cause is unknown.

Weak: "The release caused the errors."

Better: "The errors started after the release. The cause has not been established."

Shortening a sentence must not turn correlation into causation.

## Make an offer

Given: a service collects requests from two channels in one list and offers a trial. Time savings have not been measured.

Weak: "Our revolutionary platform unlocks limitless possibilities and guarantees rapid sales growth."

Better: "The service puts requests from both channels in one list. You can try it with your own requests."

Keep the useful offer. Do not add unsupported percentages or guarantees.

## Preserve format and precision

If the user asks for a table comparing three solutions, keep the table and all three solutions. Avoiding formulaic writing does not require changing the number of real options.

When asked to explain JSON, preserve the original object and edit only the surrounding explanation. Keep awkward phrasing inside a verbatim quotation. If the user asks for a revision, present it separately.

A detailed explanation should retain necessary definitions, examples, and limitations. Natural prose can be long when each paragraph helps the reader understand the subject.
